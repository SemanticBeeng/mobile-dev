# Upstream PureMVC Source

This module contains the unmodified Kotlin source files from the official [PureMVC Kotlin Multicore Framework](https://github.com/PureMVC/puremvc-kotlin-multicore-framework), pinned at commit `a6f1c7db1f168e2f015b54aeaf8978ef9c66b44e`.

The wiki lists a Maven/Gradle artifact, but the advertised coordinates were not present in Maven Central when this sample was generated. Keeping the small upstream framework source as a separate local Gradle module makes this sample reproducible without JitPack or private credentials.
